# Hi, I'm Ernesto

I'm a product engineer and team lead at [Todoist](https://todoist.com). I write about product thinking, system design, and tools that work well for both people and agents.

I've been building software since 2003 and I'm one of the creators and maintainers of [Testing Library](https://testing-library.com). These days, I'm exploring how AI changes the craft—and what good software still requires.

## Writing

I write occasionally about software, product, AI, and the changing craft of building things. No schedule—just when something feels worth saying.
